# V2 真人 Fun / Memory Gate

狀態：**pending — 尚未執行真人驗收**。程式與自動化測試完成，不代表好玩或能讓玩家記住人生。

依 [正式規格 §48～49、§51 V2-7](../../../docs/specs/V2-LIFE-EMERGENCE.md)，需要真正玩家遊玩 1～2 小時。Agent 腳本、30 遊戲日、100 年模擬與舊版 V1 browser soak 都不能代替。

## 開始方式

取得 `origin/work` 的 V2 候選版本；在專案執行 `npm ci`（尚未安裝依賴時）與 `npm run dev -- --host 0.0.0.0`，透過你的環境存取該開發服務。現有 main／公開網站未部署本次 V2。開場按「起身」，從正常角色自由玩；可嘗試交談、耕作、住所、委託與冒險。為比較新世界可用另一個瀏覽器 profile，避免覆蓋想保留的舊世界。

不用按既定腳本追進度。記住一位居民、觀察世界事件與後果；若遭遇死亡，可選本地成年居民接續。選單可匯出自動追加的遊玩紀錄。

- 與另一個新存檔／不同 seed 的體驗差異：待填
